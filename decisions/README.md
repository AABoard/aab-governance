# Decision Records

This folder stores public AAB decision records. Use decision records for choices that affect governance, standards approval, registry review, public trust, source-of-truth boundaries, or long-term contributor workflows.

## Naming

Use this format:

`ADR-0001-short-title.md`

## Template

```markdown
# ADR-0001: Title

Date: YYYY-MM-DD
Status: proposed | accepted | superseded | retired

## Context

What problem or decision need exists?

## Decision

What did AAB decide?

## Rationale

Why is this decision appropriate?

## Consequences

What changes, risks, or follow-up actions result?

## Related Links

- Issue:
- Pull request:
- Related policy:
```
