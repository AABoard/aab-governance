# Governance Roles

This folder defines public AAB roles used in GitHub collaboration and review workflows.

## Role Families

| Role | Purpose |
| --- | --- |
| Maintainer | Keeps repositories organized, reviews changes, and protects process quality. |
| Data reviewer | Reviews source trace, schema fit, and public suitability of registry data. |
| Standards reviewer | Reviews standards drafts, comments, evidence trace, and developmental fit. |
| Governance reviewer | Reviews policy, process, role, and decision-record changes. |
| Community moderator | Routes contributors, supports working groups, and keeps public discussions productive. |
| Technical maintainer | Maintains website, validation, search, export, and automation workflows. |

## Role Rules

Roles should be documented before they receive special repository permissions. Sensitive permissions should be limited to people with a clear operational need.
